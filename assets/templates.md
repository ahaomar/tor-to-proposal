# Structure templates

Formats the agent drafts into. `[FILL]` marks where user evidence is required;
nothing else may occupy a `[FILL]` slot.

## Cover letter (≤1 page — lint-enforced)

```
Dear [contact name/committee, p.X],

RE: [exact assignment title] — Reference: [exact ref no.] (p.X)
Deadline acknowledged: [submission deadline] (p.X)

[UNDERSTANDING — 2 sentences, facts only from Background/Objectives, each tagged (p.X).]

[FIT — one block per core competency from the JD:]
Requirement (p.X): “[verbatim requirement]”
[FILL: your matching evidence — quantified, traceable to CV §]

[COMPLIANCE — validity per ToR (p.X); acceptance of GCCs / no-deviation clause (p.X);
 registration status if required (p.X).]

[AVAILABILITY per start date (p.X) + contact block.]

Sincerely,
[Name exactly as in CV + credentials]
```

## Technical response — one section per scored criterion

```
## [n]. [Criterion label, verbatim from the ToR evaluation grid] (p.X, [weight] pts)

[Direct answer to every sub-element of this criterion, in the client's vocabulary.
Each factual statement about the assignment carries (p.X); each statement about
your experience carries [FILL] or CV-traceable evidence.]

[Where the methodology is asked for: approach → steps → how each ToR
 deliverable (p.X) is produced → quality control → sustainability.]
```

Ordering rule: highest weight first (unless the client's template fixes its own
order — then their order wins and template-filler maps sections into it).

## Compliance matrix row (generated by extract.mjs; complete each before audit)

```
| Requirement (verbatim, p.X) | p.X | Our response (2–3 lines / [FILL]) | Owner | Complete |
```

## CV bullet upgrade pattern (cv-gap suggestions follow this shape)

```
Before: “Responsible for M&E activities in the region.”
After:  “[FILL: n] years leading M&E for [client names], covering [FILL: n]
         evaluations in [FILL: countries]; produced [FILL: deliverable] used by
         [FILL: client] for [FILL: decision].”   (numbers user-supplied only)
```

Terminology mirroring: if the ToR says "results framework", the CV bullet says
"results framework" — not "logframe", not "M&E plan".

## Clarification questions (send before the cutoff date, p.X)

```
Subject: Request for clarification — [ref no.] — [title]

Q1. [Ambiguity in the ToR, quoted (p.X)] — please confirm whether [interpretation A or B].
Q2. [Gap between deliverables (p.X) and effort estimate (p.X)] — please confirm the expected effort split.
Q3. [Financial form field with no stated basis (p.X)] — please confirm whether [X] is included.
```

Every question must quote the ToR line it refers to. Never ask what the ToR
already answers — that signals you did not read it.
